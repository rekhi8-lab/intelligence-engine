SECTION 1 — FIRST-TIME SETUP (do this once)
--------------------------------------------------------------------------------

STEP 1: Install Python (if not already installed)
  - Download Python 3.11+ from https://python.org
  - During install, CHECK "Add Python to PATH"
  - Verify: open Command Prompt, run: python --version

STEP 2: Install all required packages
  Open Command Prompt in the Trend Scraper folder, then run:

    pip install anthropic google-generativeai praw pytrends
    pip install yt-dlp google-api-python-client youtube-transcript-api
    pip install flask flask-cors python-dotenv requests pillow pytesseract
    pip install google-auth-oauthlib google-auth-httplib2

STEP 3: Configure your API keys
  Edit the file: C:\Users\Acer\Desktop\Trend Scraper\.env
  Fill in:
    CLAUDE_API_KEY=your_key_here
    YOUTUBE_API_KEY=your_key_here
    REDDIT_CLIENT_ID=your_key_here
    REDDIT_CLIENT_SECRET=your_key_here
    REDDIT_USER_AGENT=IntelligenceEngine/3.0

  Get keys from:
    - Claude:   https://console.anthropic.com
    - YouTube:  https://console.cloud.google.com (enable YouTube Data API v3)
    - Reddit:   https://www.reddit.com/prefs/apps (create "script" app)

STEP 4: Initialise the database
  In Command Prompt (Trend Scraper folder):

    python database.py

  You should see: "Database initialised at: intelligence.db"

STEP 5: Migrate old data (if you have intelligence.json from v2)
  Only needed if upgrading from a previous version:

    python migrate.py

STEP 6: Set up Google Drive backup (see Section 5 for full details)

SECTION 2 — WEEKLY WORKFLOW (normal weekly use)
--------------------------------------------------------------------------------

Run these steps every week, in order:

--- MONDAY: Gather intelligence ---

  1. Run the full intelligence pipeline:
       python run_all.py

     This takes ~5-10 minutes. It will:
       - Scrape Reddit, YouTube, Google Trends
       - Feed data to Claude AI for analysis
       - Save results to database
       - Export intelligence.json snapshot

  2. Review the output printed to screen — check trending topics,
     content gaps, and YouTube title suggestions.


--- TUESDAY: Create content drafts ---

  3. Generate content for all three brands:
       python content_generator.py

     This creates:
       - 3 LinkedIn posts (one per brand)
       - 3 Instagram captions (one per brand)
       - 1 WhatsApp expert community prompt
       - Files saved to: output/drafts/

  4. Review and edit drafts in: output/drafts/


--- WEDNESDAY: Collect expert signals ---

  5. Get the WhatsApp discussion prompt:
       python whatsapp_import.py generate

  6. Copy the prompt and send it to your 70-member WhatsApp expert group.

  7. Collect their responses into a text file, e.g. responses_2026-04-28.txt
     Format (one response per line, or separated by ---):
       Dr Smith: Response text here
       ---
       Prof Jones: Another response here

  8. Import their responses:
       python whatsapp_import.py import responses_2026-04-28.txt

     These will automatically feed into next Monday's run_all.py at high priority.


--- THURSDAY: Post content ---

  9. Post your reviewed drafts to LinkedIn, Instagram, YouTube.


--- FRIDAY: Log performance ---

  10. Log how your content is performing:
        python auditor.py log

      Follow the prompts to enter views, likes, comments etc.

  11. For YouTube videos, auto-fetch stats with:
        python auditor.py youtube https://youtu.be/your_video_id

  12. View performance report:
        python auditor.py report


--- ANY TIME: Backup to Google Drive ---

  13. Run backup:
        python gdrive_backup.py backup

      Or let the Task Scheduler run it automatically (see Section 5).

--------------------------------------------------------------------------------

ONE-TIME SETUP:

  Step A: Create Google Cloud Project
    1. Go to: https://console.cloud.google.com
    2. Click "Select a project" > "New Project"
    3. Name it: IntelligenceEngine (or any name)
    4. Click "Create"

  Step B: Enable Google Drive API
    1. In the left menu: APIs & Services > Library

  Step C: Create OAuth Credentials
    1. In the left menu: APIs & Services > Credentials
    2. Click "+ CREATE CREDENTIALS" > "OAuth client ID"

       - User Type: External

       - Add your Gmail as test user

    5. Name: IntelligenceEngine Desktop
    6. Click "Create"
    7. Click "DOWNLOAD JSON"
    8. Rename the downloaded file to: credentials.json
    9. Move it to: C:\Users\Acer\Desktop\Trend Scraper\credentials.json

  Step D: Run first-time migration

      python gdrive_backup.py migrate

    A browser window opens. Sign in with your Google account.
    Click "Allow" to grant access.
    The file token.json is created automatically for future runs.

    Migration uploads:
      - All code files to Drive > code/
      - Database and JSON to Drive > data/

--------------------------------------------------------------------------------
SECTION 6 — TROUBLESHOOTING
--------------------------------------------------------------------------------

"ModuleNotFoundError: No module named X"
  Run: pip install X  (replace X with the module name)

"credentials.json not found"
  Follow Section 5 Step C to create and download the file.

"Invalid API key" errors
  Check your .env file — make sure there are no extra spaces or quotes around keys.
  Correct format: CLAUDE_API_KEY=sk-ant-api03-...

"No trends data" or empty Reddit results
  Reddit and Google Trends can have temporary rate limits. Try again in 10 minutes.

"Database is locked"
  Another process is using intelligence.db. Close any database browsers,
  wait a moment, then try again.

"UnicodeEncodeError" on Windows
  The terminal may not support all characters. This is handled automatically
  by the scripts. If it persists, try running in Windows Terminal instead of
  the default Command Prompt.

"Token expired" for Google Drive
  Delete token.json and run the migration again — it will re-authenticate.

Chatbot not responding
  Make sure chatbot_server.py is running (you'll see "Running on http://127.0.0.1:5000").
  Check that CLAUDE_API_KEY is set in .env.
